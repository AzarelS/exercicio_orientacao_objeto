# Exercício: Programação Orientada a Objetos (POO) em Java

Repositório acadêmico destinado ao armazenamento e organização dos exercícios práticos desenvolvidos para a disciplina de **Algoritmos e Programação** da **UNISUL**, sob a supervisão do professor **Osmar**.

O objetivo deste projeto é consolidar o aprendizado sobre o paradigma de **Programação Orientada a Objetos (POO)**, abordando desde a modelagem de entidades do mundo real até a implementação de classes, objetos, encapsulamento e relacionamento entre componentes na linguagem Java.

## Tecnologias e Requisitos

* **Linguagem:** Java (JDK 11 ou superior)
* **Ambiente de Desenvolvimento:** NetBeans (ou qualquer outra IDE compatível com Java, como Eclipse, IntelliJ IDEA, VS Code) ou editor de texto com terminal.

## Tópicos Abordados

Os algoritmos presentes neste diretório cobrem os seguintes conceitos fundamentais sobre Orientação a Objetos:

* Criação de Classes, Atributos e Métodos
* Instanciação e manipulação de Objetos (`new`)
* Métodos Construtores (padrão e sobrecarregados) e o uso da palavra-chave `this`
* Encapsulamento e Modificadores de Acesso (`public`, `private`, `protected`)
* Métodos acessores e modificadores (*Getters* e *Setters*)
* Sobrecarga de métodos (*Overloading*) e sobrescrita (*Overriding*)
* Herança (`extends`), Polimorfismo e Classes Abstratas / Interfaces
* Associação, Agregação e Composição entre classes

## Instruções de Compilação e Execução

### Via IDE (NetBeans)

1. Abra o **NetBeans** e carregue o projeto (`File > Open Project`).
2. Localize a classe principal (que contém o método `main`, ex: `Principal.java` ou `ExercicioPOO.java`) na aba de projetos (`Source Packages`).
3. Pressione `Shift + F6` (ou clique com o botão direito e selecione **Run File**) para compilar e executar o código.

### Via Terminal (Linha de Comando)

1. Abra o terminal no diretório raiz (`src`) onde os arquivos `.java` estão localizados.
2. Compile os arquivos-fonte utilizando o comando:

   ```bash
   javac *.java
   ```

3. Execute a classe principal do programa compilado com o comando:

   ```bash
   java Principal
   ```
